# StockJomla - دليل رفع الموقع على cPanel (بالعربية)

## ماذا يوجد في هذا الأرشيف؟
الملف `stockjomla-cpanel.zip` يحتوي على **النسخة المبنية (Production)** الجاهزة للرفع مباشرة على استضافة cPanel. لا تحتاج إلى Node.js، npm، أو أي أدوات أخرى على الاستضافة - فقط ملفات ثابتة (HTML/CSS/JS).

---

## 🚀 طريقة الرفع على cPanel (بالتفصيل)

### الخطوة 1: فتح مدير الملفات في cPanel
1. سجل الدخول إلى لوحة تحكم cPanel الخاصة بك.
2. من قسم **Files** اضغط على **File Manager**.
3. افتح مجلد `public_html` (أو مجلد الدومين الفرعي إن كنت تستخدم دوميناً فرعياً).

### الخطوة 2: رفع وفك الضغط
1. اضغط على زر **Upload** من الشريط العلوي.
2. ارفع ملف `stockjomla-cpanel.zip` إلى مجلد `public_html`.
3. بعد انتهاء الرفع، عد إلى File Manager واضغط بالزر الأيمن على الملف المضغوط ثم اختر **Extract**.
4. تأكد أن الملفات ظهرت مباشرة داخل `public_html` (وليس داخل مجلد فرعي). أي يجب أن يكون `index.html` موجوداً مباشرة في `public_html/`.

### الخطوة 3: التأكد من ملف .htaccess (موجود مسبقاً)
- ملف `.htaccess` موجود في الأرشيف ويقوم بتوجيه جميع المسارات إلى `index.html` (ضروري لتشغيل React Router)، تفعيل الضغط، وتخزين الملفات مؤقتاً.
- إذا كان استضافتك تستخدم **LiteSpeed** أو **Apache** (معظم الاستضافات المغربية) سيعمل تلقائياً دون أي تعديل.

### الخطوة 4: الدخول للموقع
افتح دومينك في المتصفح. ستظهر صفحة StockJomla الرئيسية.

## 🔑 الحسابات التجريبية

| نوع الحساب | البريد الإلكتروني | كلمة المرور |
|-----------|------------------|-----------|
| مورّد (تجريبي مع منتجات) | `demo@stockjomla.ma` | `demo123` |
| المسؤول (Super Admin) | `admin@stockjomla.ma` | `admin123` |

> 💡 هذه النسخة تخزن البيانات في `localStorage` داخل متصفح الزائر. إذا أردت قاعدة بيانات حقيقية وربط WhatsApp Business API، تحتاج إلى Backend (Node.js / PHP / Laravel) - هذه النسخة Frontend كاملة للعرض والتجربة.

---

## 🌐 ربط الدومين المخصص (لمشتركي Enterprise)
لأن هذه نسخة تجريبية (Static SPA)، الدومين المخصص المطلوب في لوحة التحكم هو محاكاة بصرية فقط. في الإنتاج الحقيقي تحتاج إلى:
- سجلات CNAME تشير إلى خادمك
- خادم وكيل عكسي (Nginx / Cloudflare) يوجه الدومين إلى التطبيق

---

## 💬 تفعيل الواتساب الحقيقي
التطبيق يستخدم رابط `wa.me/<phone>` الرسمي لواتساب، والذي يعمل مباشرة بدون أي API أو مفاتيح. عند ضغط الزبون على "إرسال الطلب عبر واتساب" يتم فتح واتساب ويب/التطبيق مع نص الطلبية جاهز للإرسال.

## 📁 محتويات الأرشيف
```
public_html/
├── index.html            ← الصفحة الرئيسية
├── favicon.svg           ← أيقونة الموقع
├── .htaccess             ← إعدادات Apache/LiteSpeed
└── assets/
    ├── index-*.js        ← ملف JavaScript الكامل
    └── index-*.css       ← ملف الأنماط
```

---

## 🛠️ إذا كنت تريد التعديل على الكود
الأرشيف الثاني `stockjomla-source.zip` يحتوي على **الكود المصدري الكامل** مع ملفات React. لتعديله وبنائه مرة أخرى:
```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء النسخة الإنتاجية في مجلد dist/
```
ثم ارفع محتويات `dist/` + `.htaccess` إلى `public_html`.
